Browser-KI-Messung

Misst, wie schnell das Sprachmodell Qwen3-4B direkt in deinem Browser läuft. Nichts wird an Quiltor geschickt; das Ergebnis kopierst du am Ende selbst.

Bitte die Seite nicht per Doppelklick öffnen. Bei einer Datei vom Rechner (file://) behält der Browser das Modell nicht – jeder Start lädt erneut etwa 2,5 GB herunter. Öffne den Ordner stattdessen mit npx serve . und rufe die Adresse auf, die dort angezeigt wird (meist http://localhost:3000). „Messung starten“ ist hier gesperrt.
Messung

Beim ersten Start lädt der Browser das Modell herunter: etwa 2,5 GB. Danach liegt es im Browser-Speicher und startet schneller.
