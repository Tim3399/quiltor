# MCP tool contract v1

The catalogue fixture is the cross-runtime source of truth for tool names and
input schemas. `protocolVersion` is the MCP transport version negotiated by the
host; catalogue version 1 is Quiltor's independent compatibility boundary.

Every mutation-shaped tool has effect `proposal`. It must return an unapplied
proposal with `requiresConfirmation: true`; MCP never writes manuscript or world
state. Tool removal, renaming, or a stricter existing input requires catalogue
v2. Adding an optional input or a new tool is compatible with v1.
