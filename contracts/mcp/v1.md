# MCP tool contract v1

The catalogue fixture is the cross-runtime source of truth for tool names and
input schemas. `protocolVersion` is the MCP transport version negotiated by the
host; catalogue version 1 is Quiltor's independent compatibility boundary.

Every mutation-shaped tool has effect `proposal`. An actionable result contains
an unapplied proposal with `requiresConfirmation: true`. If the shared
revision-bound integrity service proves that the requested operation is already
satisfied, the tool instead returns a non-actionable idempotent receipt with
`proposal: null`, `requiresConfirmation: false`, and `operationSatisfied: true`.
MCP never writes manuscript or world state. Tool removal, renaming, or a stricter
existing input requires catalogue v2. Adding an optional input or a new tool is
compatible with v1.

The six bounded read/resolve tools (`resolve_entity`, `get_entity`,
`get_relationships`, `find_timeline_events`, `get_world_state`, and
`search_manuscript`) delegate to the same transport-neutral application service
used by the local Assistant. MCP adds only the required `worldId` host argument;
their results remain explicitly read-only and side-effect-free.
