# Writing-data release manifest v1

`writing-data-<version>.manifest.json` is written by `tools/writing-data/build.py pack`
next to `writing-<version>.sqlite3.gz` and `LICENSE-DATA.txt` in a data release.

- `asset` describes the gzip file the app downloads; `sha256` and `bytes` are for
  integrity of that one copy.
- `sqlite.contentSha256` is the reproducibility claim: a SHA-256 over a canonical
  dump (the fixed DDL, then `metadata`, `entries`, `forms`, each ordered by every
  column, one compact JSON array per row). The same lock and the same tool commit
  give the same value on any SQLite or zlib version. `sqlite.sha256`,
  `sqliteVersion` and `zlibVersion` describe the one file that was built.
- `sources` is the lock from `fetch`: upstream URL, the archived copy in the data
  release, ETag, size and SHA-256 of the file the build read.
- `dictionarySchema` is the layout of the database (`metadata.schema`); the app
  reads forms only from schema 2.
