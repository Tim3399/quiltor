# Backup manifest v2

V2 is the current fail-closed snapshot manifest. The HTTP resource paths remain
under `/v1/`; that version names the transport API, while the manifest's
`format` field versions the stored document.

Each logical file maps to an exact lowercase SHA-256 and uncompressed byte
length. Readers verify both before any world mutation. The only logical paths
are `world.sqlite3`, `manuscripts/<portable-name>.md`, and
`profiles/<portable-name>.md`; names are NFC-normalized single filenames and
must not collide under Unicode case folding.

The snapshot `id` is SHA-256 over the manifest without `id`, encoded as UTF-8
JSON with sorted keys, no insignificant whitespace, and non-ASCII characters
unescaped. Unknown fields, duplicate JSON keys, unknown encryption modes, and
unsupported manifest versions are rejected.

V1 remains an explicit read-only compatibility format. New producers emit V2.
