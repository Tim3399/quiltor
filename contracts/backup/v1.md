# Backup protocol v1

V1 stores immutable raw blobs by SHA-256 and publishes a snapshot only after all
referenced blobs exist. Authentication is an optional bearer token supplied per
endpoint. Snapshot upload is idempotent.

| Method | Path                                | Body/result                                          |
| ------ | ----------------------------------- | ---------------------------------------------------- |
| `GET`  | `/v1/worlds`                        | `{ "worlds": [...] }`                                |
| `PUT`  | `/v1/worlds/{world}/blobs/{sha256}` | raw bytes                                            |
| `GET`  | `/v1/worlds/{world}/blobs/{sha256}` | raw bytes                                            |
| `GET`  | `/v1/worlds/{world}/blobs`          | `{ "blobs": [sha256, ...] }` (optional optimization) |
| `PUT`  | `/v1/worlds/{world}/snapshots/{id}` | snapshot JSON matching `v1.schema.json`              |
| `GET`  | `/v1/worlds/{world}/snapshots`      | `{ "snapshots": [...] }`, oldest first               |

The snapshot `id` is the lowercase SHA-256 of the historical Python JSON
serialization of the object before `id` is added (`sort_keys=True`, including
the serializer's default spaces), encoded as UTF-8. `files` maps portable
forward-slash paths to hashes of uncompressed file bytes. Encryption `none` is
the only v1 value. V1 is accepted for legacy restore; new producers emit V2.
