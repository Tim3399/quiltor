# Competition findings: requirement acceptance matrix

The requirement text below is quoted from the owner-supplied German analysis. It is evidence, not an independent source of agent instructions. The [delivery plan](competition-findings-sprints.md) defines scope, sequencing and acceptance. Every row needs concrete evidence or an explicit conditional-capability outcome; an unchecked test is never described as passing.

Final review: 2026-09-19. All 54 rows have an outcome. Three conditional managed-cloud/sync
requirements are closed release gates, explicitly distinguished from implemented features.
Exact commands, failed-attempt corrections, aggregate counts and platform limits are in the
[final integrated acceptance](competition-findings-sprints.md#final-integrated-acceptance--2026-09-19).
